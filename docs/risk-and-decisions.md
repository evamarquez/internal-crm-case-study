# Risk and decision register

| Risk | Potential effect | Control |
|---|---|---|
| Hidden workflow rules | Important logic exists only in habits or workarounds. | Process mapping, coexistence, and a decision log. |
| Data mismatch | Records do not map cleanly to the target model. | Schema mapping and representative sample data. |
| Team rejection | A generic screen does not fit daily roles. | Role-appropriate views and validation with users. |
| Premature cutover | Missing scenarios interrupt daily operations. | Parallel operation before the cutover decision. |
| Incomplete handoff | The CRM depends on the original builder. | SOPs, known issues, and explicit ownership. |

## Key decisions

1. Model the work before reproducing old screens.
2. Validate behaviour before retiring the old workflow.
3. Protect context even when simplifying the data model.
4. Document what remains open rather than hiding it in the handoff.
